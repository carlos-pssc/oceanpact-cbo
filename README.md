# OceanPact CBO

Site institucional da OceanPact CBO com a página inicial e a aba do Linkedin.

## Páginas

- `index.html`: página inicial (hero, carrossel, unidades de negócio, frota e rodapé)
- `linkedin.html`: aba do Linkedin (guia do Programa Horizonte e funcionalidades)

## Como abrir

Abra o `index.html` no navegador. Não precisa instalar nada.

## Estrutura

```
index.html
linkedin.html
assets/          imagens da página inicial
assets/li/       imagens da aba do Linkedin
assets/units/    imagens das unidades de negócio
assets/frota/    fotos das embarcações
```
